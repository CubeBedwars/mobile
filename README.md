# 📱 CubeBedwars — Mobile Edition (Android & iOS)

Native mobile application for **CubeBedwars** with touch controls, virtual analog joystick, and haptic feedback powered by Capacitor.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Add Android or iOS native platform
npx cap add android
npx cap add ios

# 3. Synchronize web assets
npm run sync

# 4. Open in Android Studio or Xcode to build APK / IPA
npm run android
npm run ios
```

## ✨ Mobile Touch Features
- Virtual analog joystick for smooth 360-degree walking and sprint acceleration
- Dedicated touch action buttons: Jump, Attack / Break, Place Block, Shop, and Chat
- Touch-drag look controls with auto pitch/yaw clamping
- Fullscreen immersive landscape mode
- Offline single-player mode with autonomous tactical AI bots
- Serverless WebRTC room code multiplayer
